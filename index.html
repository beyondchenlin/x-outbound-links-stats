最新汇总 (2026-10-18)

最有价值的 5 个技巧：

  1. 主帖无链接 + 第一回复放链接：写一个独立有价值的主帖，然后在自己的第一条回复中放外链。这是目前最推荐的方法。
  2. 使用 Bio / Link-in-bio：个人资料网站字段或专业 link-in-bio 工具是最安全的外链位置。
  3. 原生内容优先：优先发布文本、图片、视频或线程，链接作为补充。Premium 账户在链接帖上表现更好。
  4. 贴子本身必须有价值：即使不点击链接也要让读者获得价值，避免裸链接。
  5. 注意最新变化：2026年中后期有数据显示明确罚款已减少，但仍建议自测并优先使用回复方式。

发现的发外链位置与方法：

  • 自己帖子的第一条回复 (first self-reply)
  • 个人资料 Bio / Website 字段
  • 固定帖子 (Pinned post)
  • Link-in-bio 服务页面
